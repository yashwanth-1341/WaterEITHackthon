How the import reads a report

Disclosure codes decide where each number goes

Reports tag each table with a GRI or ICMM code. The import uses the code to know the table (withdrawal, discharge, storage, consumption, output), then the row labels to know the source and the water quality. This is what makes any company's file readable, not just this one.
